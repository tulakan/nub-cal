## Design Context

### Users
- **Who**: Individuals tracking daily food intake, meal plans, and body metrics.
- **Context**: Mobile-first, portrait orientation. Quick data entry is critical — users log food frequently throughout the day.
- **Job to be done**: Log food fast, see remaining macros at a glance, track body progress over time. The app must feel effortless even when entering large amounts of data initially.

### Brand Personality
- **App Name**: Nub Cal
- **Voice**: Clean, direct, functional — no fluff.
- **Tone**: Calm, efficient, trustworthy.
- **3-Word Personality**: Minimal, Precise, Effortless.
- **Emotional Goal**: Users should feel in control and never overwhelmed.

### Aesthetic Direction
- **Visual Tone**: Modern Minimal — inspired by MyFitnessPal and KcalGuru.
- **Theme**: Light mode only. Monochrome base (black/white/gray) with muted status colors.
- **Anti-references**: Overly colorful dashboards, heavy shadows, cluttered layouts.

### Design Principles
1. **Effortless Data Entry**: Minimize taps and friction. Forms should be compact, logically ordered, and fast to complete.
2. **Monochrome Clarity**: Use typography weight and spacing for hierarchy — not color. Reserve color for status indicators only.
3. **Consistent Rhythm**: Follow a strict spacing and sizing scale so the UI feels balanced and predictable.
4. **Flat & Light**: Avoid heavy cards, deep shadows, and nested containers. Use subtle borders and background tints.
5. **Mobile-First Density**: Every pixel matters. Keep layouts compact but readable — no wasted space.

## Design Tokens

### Spacing Scale
Use only these values for padding, margin, and gap:
| Token   | Value | Usage                              |
|---------|-------|------------------------------------|
| `xs`    | 4px   | Tight inner spacing, badge padding |
| `sm`    | 8px   | Default gap between inline items   |
| `md`    | 12px  | Card inner padding, section gaps   |
| `lg`    | 16px  | Page padding, major section gaps   |
| `xl`    | 24px  | Large section separators           |

### Font Scale
| Token      | Size  | Weight | Usage                          |
|------------|-------|--------|--------------------------------|
| `caption`  | 11px  | 400    | Labels, timestamps, meta info  |
| `body-sm`  | 12px  | 400    | Secondary text, nutrition info |
| `body`     | 14px  | 400    | Default body text              |
| `body-md`  | 14px  | 600    | Emphasized body (food names)   |
| `subtitle` | 15px  | 600    | Section titles                 |
| `title`    | 18px  | 700    | Card titles, stat values       |
| `display`  | 24px  | 700    | Page hero / app name           |

Font family: `Roboto, "Helvetica Neue", sans-serif` (system default via Angular Material).

### Color Palette

#### Base (Monochrome)
| Token              | Hex       | Usage                          |
|--------------------|-----------|--------------------------------|
| `--c-black`        | `#1a1a1a` | Primary text, headings         |
| `--c-gray-800`     | `#333333` | Strong secondary text          |
| `--c-gray-600`     | `#666666` | Secondary text, labels         |
| `--c-gray-400`     | `#999999` | Muted text, placeholders       |
| `--c-gray-200`     | `#e0e0e0` | Borders, dividers              |
| `--c-gray-100`     | `#f5f5f5` | Subtle backgrounds, badges     |
| `--c-gray-50`      | `#fafafa` | Card/surface background        |
| `--c-white`        | `#ffffff` | Page background                |

#### Status Colors (Muted, harmonized with monochrome)
| Token              | Hex       | Usage                          |
|--------------------|-----------|--------------------------------|
| `--c-positive`     | `#22c55e` | Remaining calories, gains      |
| `--c-negative`     | `#ef4444` | Over limit, delete actions     |
| `--c-warning`      | `#f59e0b` | Warnings, caution states       |
| `--c-positive-bg`  | `#f0fdf4` | Positive badge background      |
| `--c-negative-bg`  | `#fef2f2` | Negative badge background      |
| `--c-warning-bg`   | `#fffbeb` | Warning badge background       |

### Border & Radius
| Token          | Value              | Usage                          |
|----------------|--------------------|--------------------------------|
| `--radius-sm`  | 4px                | Badges, small chips            |
| `--radius-md`  | 8px                | Cards, input fields            |
| `--radius-lg`  | 12px               | Hero cards, modals             |
| `--border`     | 1px solid #e0e0e0  | Default card/container border  |

### Shadows
| Token          | Value                          | Usage               |
|----------------|--------------------------------|----------------------|
| `--shadow-sm`  | 0 1px 2px rgba(0,0,0,0.04)    | Subtle card lift     |
| `--shadow-md`  | 0 2px 8px rgba(0,0,0,0.08)    | Elevated elements    |

Keep shadows minimal. Prefer borders over shadows for separation.

### Interactive States
- **Touch targets**: Minimum 44px height for tappable elements.
- **Hover**: Not critical (mobile-first), but use `rgba(0,0,0,0.04)` background shift.
- **Active/Ripple**: Use Angular Material's built-in ripple.
- **Disabled**: 40% opacity.

## Component Patterns

### Section Headers
```
[Section Title]                    [Action Icon]
```
- Title: `subtitle` (15px/600)
- Action icon: 20px, `--c-gray-600`
- Bottom margin: `sm` (8px)

### Data Cards (Food Log Items, Ingredient Rows)
```
[Label/Name]                       [Value/Unit]
[Meta info | details]              [Action btn]
```
- Container: `--border`, `--radius-md`, padding `md`
- Gap between cards: `sm` (8px)
- Name: `body-md` (14px/600, `--c-black`)
- Meta: `body-sm` (12px/400, `--c-gray-600`)

### Stat Grids (Body Composition, Circumference)
- Use CSS Grid: `repeat(3, 1fr)` on mobile
- Each stat: centered, `--radius-md`, `--c-gray-100` bg
- Label: `caption` (11px, uppercase, `--c-gray-600`)
- Value: `title` (18px/700, `--c-black`)

### Tables (Nutrition Summary)
- Font size: `body-sm` (12px)
- Header: `--c-gray-100` bg, `body-sm`/500
- Cell padding: `6px 8px`
- Border: bottom only, `--c-gray-200`

### Buttons
- **Primary action**: `mat-raised-button`, black background, white text
- **Destructive action**: `mat-raised-button`, `--c-negative` background
- **Icon buttons**: 44px touch target, icon 20px
- **FAB**: Black background, white icon, `--shadow-md`

### Empty States
- Center aligned
- Icon: 40px, `--c-gray-400`
- Heading: `body-md`
- Description: `body-sm`, `--c-gray-600`

### Form Fields
- Use `appearance="outline"` consistently
- Compact height on mobile
- Labels: `body-sm`

## Layout Rules

### Page Container
- Padding: `sm` (8px) on mobile, `lg` (16px) on desktop
- Max content width: none (full width on mobile)

### Section Gaps
- Between cards/sections: `sm` (8px)
- Between major sections: `md` (12px)

### Bottom Navigation
- Height: 52px
- Icons: evenly distributed
- Active indicator: use `--c-black` for active, `--c-gray-400` for inactive

### Content Area
- Scrollable, padding: `xs` (4px)
- No horizontal overflow

---

## Anti-Patterns (Do NOT)
- ❌ Use colored text for food names or table data (reserve color for status only)
- ❌ Use box-shadow heavier than `--shadow-sm` on cards
- ❌ Mix Tailwind utilities and SCSS for the same styling concern
- ❌ Use padding/margin values outside the spacing scale
- ❌ Use font sizes outside the font scale
- ❌ Nest cards inside cards
- ❌ Use `!important` unless overriding Angular Material internals
